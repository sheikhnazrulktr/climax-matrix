# CineVerse Movie Website

A responsive front-end movie website made with HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js
- assets/

## Run
Open index.html in Chrome/Edge, or use VS Code Live Server.

## Customize
Edit the `movies` array in script.js to add your own movie titles, genres and descriptions.
Replace the demo poster backgrounds with images you own or are licensed to use.

## Copyright
This is a front-end demo. Only use movie posters, trailers, videos, music and other media that you own or have permission/licensing to use.
